# User Personas & Journey Map

## Overview

This folder contains the user personas and customer journey maps developed to better understand SmartSave's target audience, their goals, pain points, motivations, and interactions throughout the savings journey.

---

## Purpose

Developing user personas and journey maps helps ensure the proposed solution addresses real user needs and delivers a seamless, user-centered experience.

---

## Deliverables

- User Personas
- Customer Journey Map
- User Goals
- Pain Points
- Opportunities for Improvement
