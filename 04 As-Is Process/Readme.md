# As-Is Process Model

## Overview

The As-Is Process Model documents how young professionals currently manage their finances before SmartSave.

## My Contribution

⭐ Primary contributor

I modelled the current business process to identify operational inefficiencies, user frustrations, and opportunities for process improvement.

## Business Pain Points

- Manual expense tracking
- No real-time spending visibility
- Inconsistent budgeting
- Poor savings habits
- Lack of financial insights

## Outcome

The findings from this model directly informed the future-state solution.
