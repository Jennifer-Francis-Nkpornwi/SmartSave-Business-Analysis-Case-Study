# Gap Analysis

## Overview

The Gap Analysis evaluates the difference between the current financial management process and the desired future state supported by SmartSave.

## My Contribution

⭐ Primary contributor

I conducted the Gap Analysis by identifying business problems, analyzing root causes, evaluating their business impact, and recommending solution opportunities that informed the proposed product design.

## Key Findings

- Manual budgeting reduces consistency.
- Users have limited visibility into spending habits.
- Existing solutions lack personalization.
- Financial data is fragmented.
- Low engagement affects long-term savings behaviour.
